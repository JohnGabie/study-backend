# Sessão 2026-04-13 — HTTP continuação + exploração ZionHub v2 + SuperTokens

## O que foi coberto

### HTTP
- Revisão: stateless, cookies, HttpOnly/Secure/SameSite
- Estrutura completa de mensagem HTTP: linha de início, headers, body
- Content-Type e MIME types — por que os dois lados informam o tipo
- O caminho completo de objeto Python → bytes → rede → objeto Python no FastAPI
- Status codes: famílias 2xx, 3xx, 4xx, 5xx com casos reais do ZionHub
- Por que credenciais vão no body (logs) e token de sessão vai no header da response
- User enumeration no endpoint de forgot-password — ZionHub v2 já trata corretamente

### ZionHub v2
- Clonado em `projetos/zionhub-backend-v2/`
- Diferença principal: auth delegado ao SuperTokens (JWT, refresh token, bcrypt gerenciados externamente)
- 20+ endpoints de auth vs 4 na v1
- Novidades: 2FA TOTP, gerenciamento de sessões, logout global, exclusão de conta LGPD

### SuperTokens
- Clonado em `projetos/supertokens-python/`
- Lemos o signin.py — SuperTokens sempre retorna 200, independente do resultado
